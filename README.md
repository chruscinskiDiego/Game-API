# Game API — initial concept

Initial concept for a Java and Spring Web application that would retrieve player information from game APIs and persist it with JPA and H2.

## Repository status

The default branch contains this README only; the application is not implemented here.

A related code repository is [Gaming-API](https://github.com/chruscinskiDiego/Gaming-API). A user dashboard and a Discord bot were ideas for future work, not completed features of this repository.
